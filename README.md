# few-shot-medical-transductive

Reproducible empirical study: **Transductive Few-Shot Classification of Medical Images with Frozen Foundation-Model Features.**

> **No novelty claim.** This is a known-method empirical benchmark.
> Negative or mixed results are reported as-is.

---

## Research Questions

1. Does transductive inference help few-shot medical image classification when every encoder is frozen?
2. Does transductive performance degrade when the query set is class-imbalanced (Dirichlet-skewed)?

---

## Setup

```bash
pip install -r requirements.txt

# Phase 1: extract features (BloodMNIST, 224px; falls back to 128 if too slow)
python extract_features.py --dataset bloodmnist --encoders resnet50 dinov2_s clip_b16 \
       --size 224 --device cuda   # or --device cpu

# Phase 2: tune hyperparameters on val only
python tune.py --dataset bloodmnist

# Phase 3: final test run (requires configs/best_hparams.json)
python run_experiments.py --dataset bloodmnist --final --episodes 300

# Phase 4: generate tables, figures, summary
python make_plots.py

# Smoke test (synthetic features, finishes in seconds)
python run_experiments.py --smoke   # writes only to smoke/ (gitignored)

# Run all unit tests
pytest -q
```

## Protocol

### Data
- **BloodMNIST** (8 classes, hematology cell images); **PathMNIST** (9 classes) if time allows.
- Image size: **224×224** (MedMNIST+ v3). Falls back to **128** if download is prohibitively large;
  recorded here: **224×224** (BloodMNIST, `bloodmnist_224.npz`, no fallback needed).
- **Pool**: 500 images per class sampled once from train with seed 42; indices saved to
  `features/{dataset}_pool_idx.npy`. Classes with fewer than 500 train images use all available.
- Val and test splits are extracted fully.

### Encoders (all frozen, `.eval()`, `torch.no_grad()`)
| key | model | feature dim | preprocessing |
|---|---|---|---|
| `resnet50` | torchvision ResNet50 (ImageNet V1) | 2048 | ImageNet mean/std |
| `dinov2_s` | `facebookresearch/dinov2` `dinov2_vits14` | 384 | ImageNet mean/std |
| `clip_b16` | OpenCLIP ViT-B/16 (OpenAI weights) | 512 | CLIP mean/std |
| `biomedclip` | microsoft/BiomedCLIP (optional) | 512 | its own preprocess |

Features are L2-normalised (float32) before saving.

### Episode Protocol
- **Episodes**: ≥300 per condition for the final run.
- **Support**: K ∈ {1, 5, 10, 20} shots per class from the pool, `default_rng(seed + episode_id)`.
- **Query**: `n_total = C × 30` fixed; seeded from `(episode_id, imbalance_level)` independent of method and shots.
  - Balanced: 30 per class.
  - Imbalanced: Dirichlet(α · 1_C), α ∈ {1.0, 0.3} (and 0.1 optional).
- **Paired design**: every method is evaluated on the exact same episodes.

### Methods
| name | description |
|---|---|
| `proto` | nearest prototype (cosine), no hyperparameters |
| `logreg` | multinomial logistic regression on support; tune `C ∈ {0.01,…,100}` on val |
| `tim` | TIM-style: prototypes optimised via CE − λ(H(Y) − αH(Y\|X)); tune τ,λ,α on val |
| `tim_cond` | ablation: CE + λαH(Y\|X) only (no marginal entropy term) |
| `random` | uniform random baseline |
| `majority` | predicts the most frequent class of each query set (oracle sanity row, uses query labels) |

### Hyperparameter Tuning
- 100 val episodes per (encoder, shots); balanced queries only.
- Grids: τ ∈ {5,10,20,30,50,100}, λ ∈ {0.1,0.3,0.5,1,2}, α ∈ {0.25,0.5,1}, logreg C ∈ {0.01,…,1000}.
  Widened from the planned grid (τ ≤ 30, α ≥ 0.5, C ≤ 100) because the first val search picked
  edge values in nearly every setting. Still val-only; the grid used is stored in `best_hparams.json`.
- Frozen in `configs/best_hparams.json` before any test evaluation.
- Hyperparameters tuned on balanced val are used for all imbalance levels (realistic deployment).
- `tim_cond` is not tuned separately: it reuses TIM's τ, λ, α per (encoder, shots), so the
  ablation differs from `tim` only by the removed marginal-entropy term.

### Metrics
- Accuracy, macro-F1, balanced accuracy.
- Under imbalance, macro-F1 and balanced accuracy are computed **over classes present in the query set's ground truth** (absent classes excluded from the denominator). This is noted per metric.
- Aggregation: mean ± 95% CI (t-interval over episodes).
- Improvement metrics (Experiment B/C): paired Δacc, relative error reduction, win rate, Wilcoxon p-value.

## Caveats

1. **Frozen-feature, known-method empirical study; no novelty claim.**
2. Results may be negative or mixed. DINOv2 vs CLIP ranking on stain-based histology can surprise.
3. Hyperparameters were tuned on balanced val only, not re-tuned for imbalance (unless explicitly labelled ablation).
4. Macro-F1 and balanced accuracy under imbalance are computed over present classes only.
5. Query size is fixed at C×30 across all imbalance levels.
6. Pool size is 500/class (or fewer if class is smaller — logged during extraction).
7. Image size used: 224×224 (BloodMNIST).
